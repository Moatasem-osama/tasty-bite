# 🍳 TastyRecipes - Culinary & Restaurant Web App

TastyRecipes is a modern, responsive web application designed for exploring restaurant menus and recipes. Built with React and modern CSS, it features an intuitive UI with interactive recipe cards, visual badges, and dynamic layouts optimized for all device sizes.

---

## ✨ Features

* **Hero Banner:** Eye-catching layout featuring highlighted recipes and special menu items.
* **Dynamic Recipe Grid:** Responsive card layout using CSS Grid that automatically adjusts across screen sizes.
* **Interactive UI Elements:** Visual badges for popular dishes, interactive rating tags, and hover effects.
* **Modern Footer:** Complete footer with logo integration, quick links, food categories, and a newsletter subscription form.
* **Fully Responsive:** Seamlessly optimized for desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend:** React.js (JSX)
* **Styling:** CSS3 (Flexbox, CSS Grid, Media Queries)
* **Design:** Clean, modern UI with interactive hover transitions
